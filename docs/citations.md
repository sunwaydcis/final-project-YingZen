# Third-Party Code and Asset Citations

All third-party libraries and frameworks used in the development of this project are listed below with their respective license agreements and official source repositories.

## 1. Scala Programming Language (Scala Standard Library)
*   **Source URL:** [https://github.com/scala/scala3](https://github.com/scala/scala3)
*   **License:** Apache License 2.0
*   **Usage:** Core programming language and standard collections library (immutable lists, options, tries).

## 2. ScalaFX Library
*   **Source URL:** [https://github.com/scalafx/scalafx](https://github.com/scalafx/scalafx)
*   **License:** BSD 3-Clause License
*   **Usage:** Object-oriented wrapper around the JavaFX platform for Scala-native GUI elements, layouts, and event-handling.

## 3. JavaFX (OpenJFX SDK)
*   **Source URL:** [https://openjfx.io/](https://openjfx.io/)
*   **License:** GNU General Public License, version 2, with the Classpath Exception (GPLv2+CPE)
*   **Usage:** Underlying graphics toolkit and rendering engine for UI controls, properties, and layout containers.
